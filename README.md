# המעשנת — אתר קטלוג

אתר קטלוג עם פאנל ניהול, עגלה והזמנות בוואטסאפ.
רץ כשרת קטן, ויודע לעבוד גם בלי שרת כקובץ סטטי.

## הפעלה מקומית

    npm install
    npm run build
    ADMIN_PASS=הסיסמה-שלך npm start

האתר יעלה בכתובת המקומית על פורט 3000.

## העלאה ל-Render

1. להעלות את התיקייה למאגר בגיטהאב.
2. ב-Render ליצור שירות מסוג Web Service ולחבר את המאגר.
3. פקודת בנייה: npm install
4. פקודת הפעלה: npm start
5. במשתני הסביבה להגדיר:
   - ADMIN_PASS — סיסמת הניהול. **חובה**, בלעדיה השמירה חסומה.
   - DATA_DIR — הנתיב לדיסק הקבוע, למשל /var/data
6. לחבר דיסק קבוע ולמפות אותו לאותו נתיב.

**חשוב:** בלי דיסק קבוע, כל פריסה מחדש מאפסת את הנתונים לקובץ הבסיס.
הדיסק דורש תוכנית בתשלום ב-Render.

## מבנה

    server.js        השרת. מגיש את האתר ומטפל בקריאה ובשמירה של הנתונים.
    seed/data.json   נתוני הבסיס. נעתקים לדיסק בהפעלה ראשונה.
    src/             קוד המקור של האתר.
    public/          תוצר הבנייה. נוצר אוטומטית, לא נשמר במאגר.
    regression.js    חבילת הבדיקות.

## ממשק הנתונים

    GET  /api/data     קריאת הקטלוג. פתוח.
    POST /api/data     שמירה. דורש כותרת x-admin-pass.
    POST /api/login    בדיקת סיסמה בלבד.
    GET  /healthz      בדיקת חיים.

לפני כל שמירה נוצר גיבוי בשם data.json.bak.

## בדיקות

    node regression.js

החבילה מריצה למעלה ממאה בדיקות על הפאנל, העגלה, המבצע,
הנגישות, האזהרות ומקור ההזמנה.
